Fábrica de Vídeos

Atualizado em 10/11/2026 · Contato: fabricadevideos.vn@gmail.com

A Fábrica de Vídeos é uma ferramenta de uso próprio, que roda no computador do dono, para enviar e acompanhar os vídeos dos canais dele (por exemplo, Rota Leonida) no YouTube. Ela não é oferecida ao público e não tem usuários além do próprio dono.

Política de Privacidade

  • O que a ferramenta acessa: com a autorização dada na página do Google, ela envia vídeos aos canais do dono, lê o status desses vídeos e as estatísticas do canal (visualizações, curtidas, comentários e receita) pela API do YouTube e pela API do YouTube Analytics.
  • Onde os dados ficam: apenas no computador do dono. O token de autorização fica cifrado no Gerenciador de Credenciais do Windows. Nada é vendido, compartilhado ou enviado a terceiros.
  • Para que servem: publicar os vídeos no horário marcado e mostrar ao dono como cada vídeo está indo.
  • Como revogar: a qualquer momento em myaccount.google.com/permissions. Os dados guardados podem ser apagados a pedido pelo e-mail acima.
  • O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado, e os Termos de Serviço do YouTube. Política de privacidade do Google: policies.google.com/privacy.

Termos de Serviço

A ferramenta é de uso exclusivo do dono e dos canais dele. Quem a usa concorda com os Termos de Serviço do YouTube. Não há garantia de funcionamento e nenhum serviço é vendido.

Privacy Policy (English)

Fábrica de Vídeos is a private, single-user tool that runs on its owner's computer to upload and track videos on the owner's own YouTube channels. With the permission granted on Google's consent page, it uploads videos, reads their status and reads channel statistics through the YouTube Data API and YouTube Analytics API. Data stays only on the owner's computer (the token is encrypted in the Windows Credential Manager) and is never sold or shared. Access can be revoked at myaccount.google.com/permissions. Use of data received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and to the YouTube Terms of Service. Contact: fabricadevideos.vn@gmail.com.
